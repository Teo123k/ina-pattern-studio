## Implement

Define supported crochet operations and a pattern JSON contract: terminology, abbreviations, measured gauge, exact frame, yarn/hook, rows/rounds, repeat expansion, stitch totals, attachments and finishing. Start with one verified repeat/construction family. Implement checks for supported operations, count transitions and row/height calculations; unsupported techniques require review. Draft from confirmed brief/selected concept and successful validation version. Add bounded repair attempts, then surface a useful error. Distinguish estimated material/time from prototype observations.

## Acceptance

Known-good fixture passes; deliberately wrong repeat/count/increase/height fixtures fail. Changed material/measurements block stale drafts. Every draft is not-for-sale; no empty steps accepted. Mock model malformed output never reaches saved valid draft.
