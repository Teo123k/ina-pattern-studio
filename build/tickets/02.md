## Implement

Keep immutable measurement history in project data and require expected current version on updates. Persist the exact resolved validator inputs, measurement version and result. Reject construction inputs that silently override confirmed measurements. Require explicit fit tolerance with a documented finite upper bound; bound computation to avoid unbounded loops. On relevant measurement changes clear current validation and current release approval; retain historical evidence. Saving a draft must name and match its successful validation record. Concurrent enforcement belongs to ticket 03.

## Acceptance
