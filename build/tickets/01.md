## Implement

Define one shared strict measurement schema. Require finite positive diameter, height, stitch gauge and row gauge; integer positive motif repeat; nonblank fitting, yarn identity and hook size. Keep intake facts unconfirmed. Reject unknown fields and numeric strings instead of coercing them silently. Use this schema at HTTP/domain and MCP boundaries. Record centimetres/mm explicitly. Update fixtures intentionally; do not weaken tests to retain invalid old inputs.

## Acceptance

Malformed objects, zero/negative/nonfinite values, whitespace-only fitting and missing gauge fail without changing state. Valid confirmations work via service and MCP schema. Add fixtures for all failure classes.
