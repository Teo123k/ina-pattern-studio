# INA Pattern Studio governance

## Authority

Ivana is the sole design owner and approval authority for an INA pattern, its testing outcome, blog/tutorial content and Etsy listing data.

Hermes may create internal records and reviewable drafts. It may not publish, send marketing messages, spend money, purchase materials, commit to a delivery date, make legal/safety claims, or alter external account state without a separately authorised tool and the required recorded approval.

## Approval gates

| Action | Required approval |
|---|---|
| Select concept | Ivana confirms project concept ID |
| Select materials | Ivana confirms selected material option |
| Start tester pack | Ivana confirms pattern-draft version |
| Release candidate | Two prototypes, three independent testers, zero critical issues |
| Blog/tutorial final | Ivana approves exact content version |
| Etsy draft | Ivana approves final pattern, title, price, description, tags and assets |
| Etsy publication | Separate explicit approval after the draft is displayed and checked |

## Truth and evidence

- Database project records are the source of truth for live state and approvals.
- Object storage is the source of truth for original media and versioned artifacts.
- Supplier details are only confirmed when a recorded source and date are present.
- A pattern is only released when its project record contains actual test evidence.
- Hermes session history and native memory are temporary context, never evidence.
