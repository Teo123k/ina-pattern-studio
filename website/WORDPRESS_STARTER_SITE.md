# INA Pattern Studio: WordPress.com starter site

Create a free WordPress.com site. Keep Etsy as the only checkout during this stage.

## Site map

1. **Home** — a short introduction, one finished lampshade image, and the latest journal posts.
2. **About Ivana** — her making practice, London base and original-design approach. Do not claim safety certification.
3. **Crochet Lampshade Journal** — practical process posts linked to tested Etsy patterns.
4. **Pattern Library** — a hand-curated page of Etsy links. Do not add a checkout yet.
5. **Contact** — a simple contact form or Instagram link; no promised response times.

## First post template

- Title: `Making [design name]: crochet lampshade notes`
- Featured image: finished product photo that Ivana owns or is licensed to use.
- Opening: a factual description of the finished design.
- Materials/frame: only confirmed supplier and project facts.
- Making notes: actual prototype observations, never invented tips.
- Pattern link: the verified live Etsy listing URL.
- Disclosure: `This post shares making notes. The complete tested digital pattern is sold separately on Etsy.`

## INA publication rule

INA may create a WordPress draft only after Etsy publication has a verified live URL. It stores the post ID, exact content fingerprint and image URL. Ivana then approves that exact post in Telegram; INA rechecks that WordPress has not changed it before publishing. No plugin, theme, page, comment or deletion access is part of the INA publishing tool.
